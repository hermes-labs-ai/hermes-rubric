# Hermes Rubric v1.1.1 — Apache-2.0 successor release

Version 1.1.1 is the Apache-2.0 successor release of the portable assessment
core introduced in v1.1.0. It preserves the existing package behavior, public
APIs, CLI contract, evidence and coverage semantics, and documentation claims.
